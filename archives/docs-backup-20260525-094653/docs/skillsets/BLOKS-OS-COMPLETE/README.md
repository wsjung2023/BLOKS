# BLOKS OS Complete Skillset

This folder is a production-level planning pack for building BLOKS into:

- `DeskRPG-style visual multi-agent company UI`
- `OpenClaw-class agent runtime embedded inside BLOKS`
- `Local-first installable product for general users`

## Product principle

1. A normal user should install and run without extra paid tools.
2. A normal user should start with one command and one setup wizard.
3. Advanced cloud/self-hosted operation remains optional.

## How to use

1. Read [SKILLSET.md](./SKILLSET.md) first.
