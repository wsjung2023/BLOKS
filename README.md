# BLOKS OS

> AI 직원들이 실제로 일하는 가상 회사 — 당신이 사장입니다.

---

## BLOKS OS가 뭔가요?

BLOKS OS는 **AI 에이전트를 직원처럼 운영하는 오픈소스 플랫폼**입니다.

화면 속 가상 오피스에 68명의 AI 직원이 있습니다. 각자 성격, 직급, 역할이 다르고 (CEO, CTO, 마케터, 개발자, 기획자 등) 서로 대화하며 일합니다. 당신은 사장으로서 일을 지시하고, 위험한 행동은 직접 승인하거나 거절합니다.

ChatGPT나 Claude에게 단순히 질문하는 것과 달리, BLOKS OS는 **여러 AI가 팀으로 협력**해서 일하는 과정 전체를 보여줍니다.

---

## 이걸로 뭘 할 수 있나요?

### 🏢 가상 오피스 월드 뷰
2D RPG 게임처럼 생긴 사무실에서 AI 직원들이 책상에 앉아 일하거나, 회의실에 모이거나, 라운지에서 쉬는 모습을 실시간으로 볼 수 있습니다. 각 직원의 말풍선이 뜨고 상태가 바뀌는 걸 직접 눈으로 확인할 수 있습니다.

### 📋 프로젝트 & 태스크 관리
프로젝트를 만들고 그 안에 할 일(태스크)을 추가해서 AI 직원에게 배정합니다. AI가 실제로 그 일을 처리하고 결과물을 돌려줍니다.
- 보고서 작성
- 코드 리뷰
- 데이터 분석
- 전략 기획
- 콘텐츠 제작

### 🤖 멀티 AI 오케스트레이션
하나의 태스크를 여러 AI가 협력해서 처리합니다. 예를 들어 전략팀 AI가 기획하고, 개발팀 AI가 검토하고, PM AI가 일정을 조율하는 식으로 실제 팀처럼 돌아갑니다.

### ✅ 결재 센터 (L0~L3 위험 등급)
AI가 중요한 행동을 하기 전에 반드시 승인을 요청합니다. 위험도에 따라 4단계로 나뉩니다.
- **L0** — 낮은 위험 (자동 처리)
- **L1** — 주의 필요 (1인 승인)
- **L2** — 중요한 행동 (상위 결재 필요)
- **L3** — 매우 위험 (최고 관리자 승인)

승인하거나 거절하거나, 조건을 달거나 할 수 있습니다.

### 📜 감사 로그
AI가 한 모든 행동이 기록됩니다. SHA-256 해시 체인으로 위·변조가 불가능하고, CSV나 JSONL 형식으로 내보낼 수 있습니다. "언제, 누가, 무엇을, 왜 했는지" 전부 추적합니다.

### 🚨 킬 스위치
AI가 이상한 행동을 하거나 긴급 상황이 생기면 킬 스위치 하나로 모든 AI 실행을 즉시 멈출 수 있습니다.

### 👥 68명 AI 직원 관리
각 AI 직원의 프로필, 성격, 현재 상태, 업무량, 피로도를 확인하고 관리합니다. 직원마다 쓰는 AI 모델이 다릅니다 (GPT-4o, Claude, Gemini 등).

### 🗺️ 맵 에디터
가상 오피스 레이아웃을 직접 편집할 수 있습니다. 책상 배치, 회의실 위치, 각 층 구조를 원하는 대로 바꿀 수 있습니다.

### 📊 성능 지표 & 분석
AI 직원들의 응답 속도, 성공률, AI 비용, 대기열 현황 등을 대시보드로 확인합니다.

### 💬 에이전트 메시지
AI 직원들이 서로 주고받는 메시지를 실시간으로 볼 수 있습니다. 어떤 AI가 어떤 AI에게 무슨 내용을 전달했는지 확인할 수 있습니다.

### 🧠 AI 캐릭터 메모리
각 AI 직원이 이전에 했던 일, 배운 것들을 기억합니다. 시간이 지날수록 더 효율적으로 일합니다.

### 📁 산출물(Artifact) 관리
AI가 만들어낸 결과물(문서, 보고서, 코드 등)을 모아서 관리하고, 버전별로 추적할 수 있습니다.

### 🎭 데모 시나리오
미리 준비된 시나리오를 실행해서 BLOKS OS가 어떻게 동작하는지 빠르게 체험할 수 있습니다.

### 📝 프롬프트 관리
AI 직원들에게 반복적으로 사용하는 지시문(프롬프트)을 템플릿으로 저장하고 재사용합니다.

### 🏗️ 조직도 & 직원 디렉토리
전체 AI 직원 목록, 부서별 구조, 각 직원의 역할과 권한을 한눈에 확인합니다.

### ⚡ 실시간 알림 스트림
AI가 무언가를 하면 화면에 실시간으로 알림이 뜹니다. 새로고침 없이 모든 변화가 즉시 반영됩니다.

## 설치하기

### 1단계: 필요한 프로그램 설치

아래 세 가지가 없으면 먼저 설치해주세요.

**Node.js** (JavaScript 실행 환경)
- [nodejs.org](https://nodejs.org) 에 접속
- "LTS" 버전 다운로드 버튼 클릭 → 설치

**pnpm** (패키지 관리자)
- Node.js 설치 후 터미널(명령 프롬프트)을 열고 아래 입력:
```
npm install -g pnpm
```

**Git** (코드 다운로드 도구)
- [git-scm.com](https://git-scm.com) 에서 다운로드 → 설치

> **터미널 여는 방법**
> - Windows: 키보드에서 `Windows키 + R` → `cmd` 입력 → 엔터
> - Mac: `Command + Space` → `터미널` 검색 → 엔터

---

### 2단계: BLOKS OS 다운로드

터미널에 아래를 한 줄씩 입력하세요.

```bash
git clone https://github.com/wsjung2023/BLOKS.git
cd BLOKS
pnpm install
```

`pnpm install`은 시간이 좀 걸립니다 (1~3분). 기다려주세요.

---

### 3단계: 실행

```bash
pnpm bloks-os start
```

잠시 후 브라우저가 자동으로 열리면서 BLOKS OS가 실행됩니다. 🎉

> 브라우저가 자동으로 안 열리면 직접 `http://localhost:3000` 을 주소창에 입력하세요.

설치 즉시 68명의 AI 직원이 로드됩니다. API 키 없이도 가상 오피스, 태스크 보드, 결재, 감사 로그, 맵 에디터 등 대부분의 기능을 바로 사용할 수 있습니다.

---

### 4단계: AI 기능 켜기 (선택사항)

AI 직원이 **실제로 생각하고 대화하고 일**하게 하려면 AI API 키가 필요합니다.

```bash
pnpm bloks-os init
```

실행하면 아래를 차례대로 물어봅니다. 갖고 있는 것만 입력하고, 없는 건 그냥 Enter를 누르세요. 세 가지 중 하나만 있어도 됩니다.

| AI 서비스 | 키 형식 | 발급 주소 |
|-----------|---------|-----------|
| OpenAI (GPT-4o) | `sk-proj-...` 또는 `sk-...` | platform.openai.com |
| Anthropic (Claude) | `sk-ant-...` | console.anthropic.com |
| Google AI (Gemini) | `AIza...` | aistudio.google.com |

입력한 키는 **이 컴퓨터에만** 저장됩니다. 다른 사람과 공유되지 않습니다.

**API 키란?**
AI 서비스를 사용하는 일종의 비밀번호입니다. 본인 계정에서 직접 발급받아야 하며, 사용량에 따라 소액의 비용이 발생할 수 있습니다. (대부분의 서비스가 월 $5~18 수준의 무료 크레딧을 제공합니다.)

## 자주 묻는 질문

**Q. Docker, Supabase, Redis가 필요한가요?**  
필요 없습니다. 아무것도 설치하지 않아도 됩니다.

**Q. 인터넷이 없어도 되나요?**  
가상 오피스, 태스크 보드, 결재, 감사, 맵 에디터 등 대부분의 기능은 인터넷 없이도 됩니다. AI 직원이 실제로 응답하는 기능만 인터넷이 필요합니다.

**Q. 비용이 드나요?**  
BLOKS OS 자체는 완전 무료입니다. AI API 키를 사용하면 OpenAI·Anthropic·Google에 사용량만큼 소액의 비용이 발생합니다. AI 없이 쓰면 비용은 0원입니다.

**Q. 데이터는 어디에 저장되나요?**  
내 컴퓨터 안 `.bloks-data/local-db.json` 파일에 저장됩니다. 인터넷에 올라가지 않습니다.

**Q. 종료하려면 어떻게 하나요?**  
터미널에서 `Ctrl + C` 를 누르면 됩니다.

**Q. 다시 시작하려면?**  
터미널에서 BLOKS 폴더로 이동 후 `pnpm bloks-os start` 를 다시 입력하면 됩니다.

**Q. AI 직원이 말을 안 해요.**  
API 키를 아직 입력하지 않아서입니다. `pnpm bloks-os init` 을 실행해서 API 키를 입력해주세요.

## 개발자를 위한 정보

```bash
pnpm dev          # 개발 서버 실행 (코드 수정 시 자동 재시작)
pnpm test         # 테스트 실행
pnpm lint         # 타입 검사
```

**기술 스택**

| 레이어 | 기술 |
|--------|------|
| 프론트엔드 | Next.js 15, Phaser 3 (월드), React |
| 백엔드 | Express, BullMQ |
| 데이터 | 로컬 JSON (기본) / Supabase (선택, `BLOKS_PROFILE=connected`) |
| AI | OpenAI (GPT-4o), Anthropic (Claude), Google AI (Gemini) |

**클라우드 연결 모드** (팀 협업이 필요할 때)

여러 명이 같은 데이터를 공유하려면 `.env` 파일에 아래를 추가합니다.

```bash
BLOKS_PROFILE=connected
SUPABASE_URL=https://[ref].supabase.co
SUPABASE_SERVICE_ROLE_KEY=...
REDIS_URL=redis://...
```
